# Nimbus Desk — product overview

Nimbus Desk is a fictional helpdesk product used only as sample knowledge for this RAG chatbot.

Core features:
- Ticket inbox with SLA timers and assignment rules
- Knowledge base articles that agents can search while chatting
- Outbound email from a verified domain
- A public status page for incidents

Supported plans are Starter, Team, and Enterprise. Starter includes 3 agents and email-only channels. Team adds chat and a shared inbox. Enterprise adds SSO, audit logs, and a dedicated success manager.

Data is stored in the customer's chosen AWS region. Backups run nightly. Retention on the Team plan is 1 year. Retention on Enterprise is 7 years.
